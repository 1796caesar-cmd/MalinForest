MalinForest — оновлення через налаштування

1. Завантажте вміст цього ZIP у корінь репозиторію GitHub (зберігаючи папки).
2. Після успішної збірки main новий пункт: Налаштування → Оновлення додатка.
3. Для публікації НОВОЇ версії створіть Git tag v1.6 (наступна v1.7 тощо) на потрібному коміті та запуште його. GitHub Actions збере підписаний APK з версією 1.6 і опублікує його в Releases.
4. У налаштуваннях додатка натисніть Перевірити оновлення. Програма перевірить останній GitHub Release і завантажить APK, після чого Android попросить підтвердити встановлення.
5. Репозиторій та GitHub Releases мають бути публічними. У Settings → Actions → General → Workflow permissions дозвольте Read and write permissions, якщо публікація релізу отримує 403.
6. Підпис використовується з наявних GitHub Secrets. Не змінюйте keystore.
7. На Android 8+ може знадобитися дозволити встановлення APK із цього джерела.
8. Версія для збірок main залишається 1.5; для релізу версія автоматично береться з тега v1.6, v1.7 тощо.
