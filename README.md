# ForestKiosk — інтерактивна панель

Android-додаток: локальні відео → дотик → https://malinapk.net/ → таймер бездіяльності → відео.

## Функції
- Відео з вибраної папки на пристрої, за алфавітом, циклічно; відео призупиняється при переході на сайт.
- Напис із плавним підстрибуванням, постійна верхня панель із годинником, датою, температурою та прогнозом на ранок/день/вечір.
- Адаптивне компонування; повноекранний режим; сайт у WebView.
- Утримуйте верхню панель або напис для налаштувань: вибір папки, 30 с / 1 / 2 / 5 хв, звук, оновлення списку.
- Погода: **поточна реалізація використовує Open-Meteo**, а не Sinoptik (у Sinoptik не підтверджено стабільний публічний API). У налаштуваннях є посилання на Sinoptik. Не позначайте ці дані як дані Sinoptik.
- Дані погоди оновлюються кожні 15 хв, без інтернету показується повідомлення.

## Відео
1. На панелі створіть папку `Внутрішня пам’ять/Movies/ForestKiosk`.
2. Покладіть туди MP4 (найкраще H.264 + AAC).
3. Відкрийте застосунок, утримуйте верхню панель → «Вибрати папку» → Movies → ForestKiosk → «Використати цю папку».
4. При зміні файлів у папці застосунок оновить список протягом 15 хв; можна примусово через меню.

## Збірка GitHub
1. Створіть порожній GitHub репозиторій.
2. Розпакуйте ZIP. Завантажте **вміст папки ForestKiosk** у корінь репозиторію, разом із прихованою папкою `.github`.
3. Actions → Build Android APK → Run workflow (або дочекайтеся збірки після push).
4. Відкрийте успішний запуск → Artifacts → ForestKiosk-debug-apk → завантажте ZIP з APK.

## Зауваження
- Сумісність залежить від Android System WebView та підтримуваних відеокодеків панелі.
- APK є debug-збіркою; підписання релізної версії потребує окремого ключа.
- Не тестувалося на фізичній сенсорній панелі.
- В Android 11+ вибір папки здійснюється системним діалогом; програма не отримує доступ до всіх файлів пристрою.
