MalinForest — оновлення
1. Розпакуйте ZIP.
2. Завантажте папку app в корінь репозиторію MalinForest на GitHub (Add file -> Upload files).
3. Підтвердьте Commit changes і дочекайтеся APK у Actions.

Зміни:
- Соціальні мережі Instagram, Facebook, YouTube блокуються у WebView.
- У святах не показуються «День ангела», іменини, «Хто народився».
- Нижня стрічка циклічна, без порожньої паузи між останньою та першою новиною.
- Нові новини підхоплюються на межі циклу.
- Решта налаштувань та функцій збережені.

Примітка: це оновлення вихідного коду; роботу APK необхідно перевірити після GitHub Actions.
